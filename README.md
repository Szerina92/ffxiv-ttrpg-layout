# The FFXIV-TTRPG-Layout for FoundryVTT
This module adds a journal style for the FFXIV-TTRPG System.

## Requirements
* FFXIV TTRPG System for FoundryVTT

## How to install
Copy the following link into Foundry's manual module installation field: `https://github.com/Szerina92/ffxiv-ttrpg-layout/releases/download/latest/module.json`

## Content
* Simple Layout
* Rule tooltips
* Quest Summary Editor
* Visual Job Summary
* Embed for different item-types and actors (NPCs)
